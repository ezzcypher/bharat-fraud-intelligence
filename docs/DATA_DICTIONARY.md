# Data dictionary

The full column registry (1,050 rows, 19 datasets) was profiled from the actual files in the private runtime. It is **not published**, because it contains example values taken from licensed data; this page keeps the dataset-level summary. None of the datasets below is included in this repository (see DATA_PIPELINE.md). Every row is profiled from the actual file (Stage 1/2). Meanings come from the Phase 5 availability audit, file contracts, or are marked 'inferred from column name'.

Rules:
- BFI v1 and BFI v2 are separate projects and are never joined.
- `TransactionID`, `card1-6` and `customer_id` are not treated as real customers or payment methods.
- Labels (`isFraud`, `is_fraud`, `observed_dataset_label`, `actual_is_fraud`) are evaluation-only.

## Synthetic example
`examples/synthetic_transactions.csv`: 2,000 fictional rows in the IEEE-CIS column format (`TransactionID, TransactionDT, TransactionAmt, ProductCD, card4, card6, P_emaildomain, isFraud, data_origin`). Every row has `data_origin = SYNTHETIC`; `isFraud` is random and carries no signal. See DATA_PIPELINE.md.
